# 레이아웃 수정 내역

원본: `SKU Capstone Project Android` (kgj22 브랜치, Heesu 디자인)
이 폴더는 원본을 그대로 복사한 뒤 아래 7개 파일만 수정한 것입니다. 나머지 파일은 원본과 동일합니다.

## 1. 하단바 선택 표시가 가로/태블릿에서 납작하게 늘어나는 문제

- `app/src/main/res/drawable/bg_home_nav_selected.xml`
  - 이전: 칸 전체를 채우는 타원(oval) → 칸이 넓어지면 납작하게 늘어남
  - 이후: 칸 크기와 상관없이 **가운데 56dp 고정 원** (`layer-list` + `gravity="center"`)
  - 색을 바꾸려면 `#FFD9B8`만 수정
  - 홈, 수면, SmartThings(가이드), 정책 화면 하단바에 모두 적용됨

## 2. 기기 크기/글꼴 크기에 따라 글씨가 잘리는 문제

카드 높이가 고정값이라 내용이 넘치면 잘리던 것을
`layout_height="wrap_content"` + `minHeight="원래 값"`으로 변경.
평소에는 원래 디자인 크기 그대로, 내용이 넘칠 때만 카드가 늘어납니다.

| 파일 | 카드 id | 원래 높이 |
|---|---|---|
| `activity_menuactivity.xml` | `cardEnvironmentSummary` (아이방 온도) | 170dp |
| | `cardSleepSummary` (최근 수면) | 170dp |
| | `cardVaccineSchedule` (예방접종 예정) | 104dp |
| `activity_grape.xml` | `cardSleepScore` (수면 점수) | 342dp |
| | `cardSleepTrend` (수면 점수 추이) | 302dp |
| | `cardSleepInsight` (수면 인사이트) | 250dp |
| `activity_environment.xml` | `blockAutoControl` (자동 제어) | 142dp |
| | `cardTemperature` (현재 온도) | 222dp |
| | `cardHumidity` (현재 습도) | 222dp |
| | `devicePanel` (연결된 기기) | 470dp |
| `activity_gpt_report.xml` | `cardReportScore` (리포트 점수) | 264dp |
| `activity_mypage.xml` | `profileHeroCard` (프로필 상단) | 202dp |
| `activity_policy.xml` | `policyHeroCard` (정책 상단) | 156dp |

### 함께 수정한 것
- `activity_menuactivity.xml` 홈 상단 카드 2개: `android:layout_gravity="fill"` 추가
  (한쪽 카드만 늘어나도 같은 줄의 두 카드 높이가 맞춰지도록)
- `activity_grape.xml` 수면 인사이트의 `btnGuideRead`(가이드 읽기 버튼):
  카드 바닥에만 붙어 있던 것을 본문(`tvInsightBody`) 아래에도 연결
  (`constraintTop_toBottomOf` + `marginTop 16dp` + `vertical_bias 1`)
  → 본문이 길어져도 버튼이 글씨 위에 겹치지 않고 카드가 늘어남

## 그대로 둔 것
- 아이콘, 버튼, 원형 점수 링(`sleepScoreRing`), 차트 영역(`chartShell`) 등 크기가 정해져야 하는 요소
- `cardSleepLive`(아기방 실시간 보기): 잘리지 않아서 유지
- 하단바 메뉴 클릭 연결(기능 없음), 태블릿 전용 레이아웃(`layout-sw600dp`)은 만들지 않음

   - 기기: 작은 폰 / Pixel Tablet / 가로 화면
   - Font scale: 1.0, 1.3
2. 괜찮으면 위 7개 파일을 원본 `SKU Capstone Project Android`의 같은 위치에 덮어쓰기

# 2차 수정 (폴드 외부화면/가로 화면 확인 후)

## 3. 상단 상태바에 화면 위쪽이 가려지는 문제
- 앱이 targetSdk 36이라 Android 15 이상에서 화면이 상태바 밑까지 그려짐(edge-to-edge 강제)
- 각 화면 루트에 `android:fitsSystemWindows="true"` 추가
  - 대상: camera, environment, gpt_report, grape, main, menuactivity, mypage, policy,
    policy_detail, reset_password, schedule, sign, terms
  - 제외: report, userexplore (코드에서 이미 여백 처리), 목록 아이템 레이아웃

## 4. 로그인 화면 (`activity_main.xml`)
- 가로/작은 화면에서 입력칸, 회원가입/로그인 버튼, 문구가 서로 겹침
- 전체를 `ScrollView`로 감싸고, 버튼 묶음을 입력칸 아래에 연결(`constraintTop_toBottomOf`)
  → 세로에서는 기존처럼 버튼이 아래쪽에, 공간이 부족하면 스크롤

## 5. 마이페이지 (`activity_mypage.xml`)
- 공동 양육자 / SmartThings 오른쪽 `+` 버튼이 검은 네모로 보이던 문제
  - 512px 이미지를 `scaleType="center"`로 가운데만 잘라 보여주던 것 → `fitCenter` + 아이콘 색(#795D43)
- "연결된 스마트 기기가 없습니다" 줄이 카드 밑으로 튀어나와 보이던 문제
  - 음수 여백(-8dp)과 배경색 차이 때문 → 여백 10dp, 카드와 같은 둥근 배경
- "모든 변경사항 저장" 버튼이 두 줄 + 28sp로 너무 커서 입력칸을 많이 가림
  - 한 줄, 20sp, 높이 104dp → 64dp, 스크롤 하단 여백 150dp → 110dp

## 6. 정부 정책 모아보기 (`activity_policy.xml`)
- 상단 툴바 고정 높이(128dp) 때문에 부제목이 잘림 → 최소 높이 방식

## 7. 수면 화면 (`activity_grape.xml`, `GrapeActivity.java`)
- "아기방 실시간 보기" 카드의 제목/부제가 위쪽에 겹쳐 보이던 문제 → 아래쪽 정렬 체인으로 수정
- 수면 점수 추이의 "데이터 없음" 문구가 잘림(차트는 줄바꿈 안 됨) → "아직 수면 데이터가 없습니다"로 짧게
  - ※ 이 항목만 Java 파일 수정

## 8. 작은 알약형 텍스트(고정 높이 → 최소 높이)
- 환경: "쾌적함", "적정" / 리포트: "오늘 아침의 인사이트" / 수면: 상태 문구, "가이드 읽기" / 홈: "95%"

## 적용 방법 (2차 포함)
`app/src/main/res/layout`의 수정된 레이아웃, `res/drawable/bg_home_nav_selected.xml`,
`java/.../GrapeActivity.java`를 원본 같은 위치에 덮어쓰기
